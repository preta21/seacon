Verilog硬件建模

本课实现一个简单的调制器和解调器。调制器根据编码对数据做变化；解调器根据数据特征判断出原始编码。

调制器原始Verilog代码如下：

代码预览
`timescale 1ns / 1ps
module qpsk_modulator #(
parameter signed [11:0] AMPLITUDE = 12'sd1024
)(
input wire clk,
input wire rst_n,
input wire bit_valid,
input wire [1:0] bit_pair,
output reg symbol_valid,
output reg signed [11:0] i_out,
output reg signed [11:0] q_out
);
// Gray mapping:
// 00 -> (+I, +Q), 01 -> (-I, +Q)
// 11 -> (-I, -Q), 10 -> (+I, -Q)
always @(posedge clk or negedge rst_n) begin
if (!rst_n) begin
symbol_valid <= 1'b0;
i_out <= 12'sd0;
q_out <= 12'sd0;
end else begin
symbol_valid <= bit_valid;
if (bit_valid) begin
i_out <= bit_pair[0] ? -AMPLITUDE : AMPLITUDE;
q_out <= bit_pair[1] ? -AMPLITUDE : AMPLITUDE;
end
end
end
endmodule
代码中，将2bit的编码映射为12bit的I/Q值。
